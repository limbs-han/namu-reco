# 나무위키 개인화 추천 — 정적 데이터 배포

이 브랜치(GitHub Pages)는 크롬 확장프로그램 **나무위키 개인화 추천**(비공식)이
사용하는 사전계산 추천 데이터를 정적 파일로 서빙합니다.

- `manifest.json` — 빌드 버전·샤드 수·네임스페이스 상수
- `popular.json` — PageRank 상위 100 문서 제목 (콜드스타트용)
- `nbr/0000.json.gz` ~ `nbr/1023.json.gz` — 문서별 이웃 사전계산 샤드

## 출처·라이선스

이 데이터는 [나무위키](https://namu.wiki) 문서 본문(2021-03-01 공식 덤프)을
가공한 **2차적 저작물**입니다. 원저작물은
[CC BY-NC-SA 2.0 KR](https://creativecommons.org/licenses/by-nc-sa/2.0/kr/)로
배포되며, 동일조건변경허락(SA) 조항에 따라 **이 데이터 자체도
CC BY-NC-SA 2.0 KR로 제공합니다** — 출처 고지만으로는 부족하며, 이 선언이
라이선스 의무의 일부입니다.

- 저작자 표시: 각 추천 항목은 해당 나무위키 문서 URL(`https://namu.wiki/w/<제목>`)로
  연결되어 원문과 저작자 표시를 확인할 수 있습니다.
- 비영리: 이 프로젝트는 어떤 형태로도 수익화하지 않습니다.

개인정보처리방침은 [PRIVACY.md](./PRIVACY.md)를 보십시오.
