# 나무위키 개인화 추천 (비공식)

나무위키를 읽다 보면 늘 "다음엔 뭘 읽지?"가 아쉽습니다. 이 크롬 확장프로그램은
**내가 나무위키에서 읽은 문서들을 바탕으로, 다음에 읽을 만한 문서를 추천**해 줍니다.

- 나무위키를 평소처럼 읽기만 하면 됩니다. 어떤 문서를 얼마나 오래 읽었는지로
  관심사를 파악해 몇 분 안에 추천이 만들어집니다.
- 추천은 세 곳에서 만납니다: 나무위키 상단 메뉴의 **"추천 문서" 탭**, 툴바
  확장 아이콘의 **팝업**, 그리고 문서 옆의 **"연관 문서" 위젯**(지금 읽는 문서
  본문과 이어지는 문서들).
- 추천 목록은 **이유별로 묶여** 표시됩니다 — "오래 읽은 「그 문서」와 가까운 문서",
  "「그 문서」에서 이어지는 문서" 같은 이유가 묶음 제목이 됩니다. 지금 보고 있는
  문서나 이미 읽은 문서는 목록에 다시 나오지 않습니다.
- 페이지 안의 추천을 클릭하면 새로고침 없이 부드럽게 이동하고, 팝업에서는 새
  탭으로 열립니다.
- 이제 막 설치해서 읽은 기록이 없다면 나무위키 인기 문서를 대신 보여주고,
  읽기 시작하면 점차 내 취향으로 바뀝니다.
- 관심사는 시간이 지나면 자연스럽게 잊힙니다(7일마다 가중치 절반) — 지난달에
  몰아 본 주제가 계속 따라다니지 않습니다.

## 내 기록은 어디에 저장되나요?

**전부 내 브라우저 안에만** 저장됩니다. 이 확장에는 서버가 없습니다.

- 수집: 방문한 나무위키 문서의 제목·방문 시각·체류시간, 그리고 열람한 문서
  본문의 내부 링크 목록(추천 보조용). 이게 전부입니다.
- 클릭·스크롤·키 입력은 수집하지 않고, 어떤 데이터도 외부로 전송하지 않습니다.
  확장이 네트워크로 받아오는 것은 공개 추천 데이터(정적 파일)뿐입니다.
- 기록은 90일이 지나면 자동 삭제되고, 확장을 제거하면 브라우저가 데이터를 함께
  지웁니다. 자세한 내용: [개인정보처리방침](publish_docs/PRIVACY.md)
- 요구 권한은 알람(5분 주기 추천 갱신) 하나뿐입니다.

## 설치

아직 크롬 웹스토어에 등록되지 않아 개발자 모드로 설치합니다.

1. 이 저장소를 내려받습니다 (Code → Download ZIP → 압축 해제)
2. 주소창에 `chrome://extensions` 입력 → 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 안의 `extension` 폴더 선택
4. 나무위키에서 문서 몇 개를 읽고 잠시 뒤 확장 아이콘을 눌러 보세요

## 자주 묻는 것

- **추천이 왜 비어 있나요?** — 설치 직후라면 첫 갱신(최대 5분)을 기다려 주세요.
  이후에도 비어 있다면 나무위키 문서를 몇 개 읽으면 채워집니다.
- **최근에 생긴 문서도 추천되나요?** — 추천 기반 지도는 2021년 나무위키 공개
  덤프로 만들어져 있어서, 그 이후 신설된 문서는 열람한 페이지의 본문 링크를
  활용한 보조 방식으로 추천됩니다.
- **인터넷이 끊기면?** — 추천 데이터를 못 받아온 사이클은 조용히 건너뛰고,
  연결이 돌아오면 자동으로 회복됩니다.

## 어떻게 만들어졌나 (개발자용)

추천 데이터는 나무위키 공개 덤프(87만 문서)를 오프라인 파이프라인으로 가공해
만듭니다: Spark 파싱 → PageRank → 문서 임베딩 → 이웃 사전계산(임베딩+분류 혼합)
→ 품질 게이트 → GitHub Pages 정적 배포(1,024샤드, 154MB). 품질 게이트(링크 해석률
95.6%, 점수 유한성 등)를 통과하지 못하면 배포가 기계적으로 차단됩니다.
