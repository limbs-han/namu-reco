# 개인정보처리방침 — 나무위키 개인화 추천 (비공식)

이 확장프로그램은 나무위키 문서 추천을 위해 다음 데이터를 **사용자 기기 안에서만**
처리합니다.

## 수집 항목

1. **방문 기록(Web history)** — 사용자가 연 나무위키 문서의 제목, 방문 시각,
   체류시간(화면에 보인 구간만, 최대 30분).
2. **웹사이트 콘텐츠(Website content)** — 열람 문서 본문의 내부 링크 목록을
   추천 폴백용으로 기기 내 저장(90일 보존).

클릭·마우스 위치·스크롤·키 입력·네트워크 감시 등 사용자 활동(User activity)은
수집하지 않습니다.

## 저장·전송

- 모든 데이터는 브라우저 IndexedDB(사용자 기기 내부)에만 저장됩니다.
- **외부 서버로 전송하지 않으며**, 제3자 제공·판매·광고 활용이 없습니다.
- 확장프로그램이 네트워크로 받아오는 것은 공개 정적 추천 데이터
  (GitHub Pages)뿐이며, 이 요청에 사용자 데이터가 실리지 않습니다.

## 보존 기간

- 방문 이벤트·수집한 내부 링크 목록: **90일** 경과 시 자동 삭제.
- 관심 프로필 행: **90일 무활동**이고 가중치가 소멸(유효 가중치 0.01 미만)하면 삭제.
- 확장프로그램을 제거하면 브라우저가 IndexedDB 데이터를 함께 삭제합니다.

## 제한적 사용(Limited Use)

수집 데이터는 위 추천 기능 제공 목적으로만 사용하며, Chrome Web Store
사용자 데이터 정책의 Limited Use 요건을 준수합니다.
